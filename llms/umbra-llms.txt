## API Reference
- [Create Task](https://docs.canopy.umbra.space/reference/create_task.md): Creates a new task. New tasks begin with status ACTIVE, and should transition to SUBMITTED, or REJECTED within a few minutes. Query tasks by id for status updates.
- [Cancel Task](https://docs.canopy.umbra.space/reference/cancel_task-1.md): Requests cancellation of a previously submitted task. A task can only be canceled if it's status is one of SCHEDULED, SUBMITTED, ACCEPTED, ACTIVE. If this operation fails, a 422 will be returned.
- [Get Task](https://docs.canopy.umbra.space/reference/get_task-1.md)
- [Post Search Tasks](https://docs.canopy.umbra.space/reference/post_search_tasks.md): Search Tasks using a variety of available filters
- [Archive Tasks](https://docs.canopy.umbra.space/reference/create_archive_tasks.md)
- [Create Feasibility](https://docs.canopy.umbra.space/reference/create_feasibility.md): Creates a feasibility request for the given constraints. Feasibilities begin with status RECEIVED, and should transition to COMPLETED or ERROR within a few minutes. Poll feasibility by id until status is COMPLETED, upon which opportunities will also be returned.
- [Get Feasibility](https://docs.canopy.umbra.space/reference/get_feasibility.md): Returns feasibility by id. When status is COMPLETED, the opportunities array will be populated with opportunities.
- [Get Collect](https://docs.canopy.umbra.space/reference/get_collect.md)
- [Post Search Collects](https://docs.canopy.umbra.space/reference/post_search_collects.md): Search Collects using a variety of available filters
- [Get Restricted Access Areas](https://docs.canopy.umbra.space/reference/get_restricted_access_areas.md): Returns a GeoJSON FeatureCollection of locations where Tasking is disallowed for your organization
- [Overview](https://docs.canopy.umbra.space/reference/v2-stac-overview.md)
- [Landing Page](https://docs.canopy.umbra.space/reference/landing_page__get.md): Endpoint.
- [Advanced Search](https://docs.canopy.umbra.space/reference/search_search_post-2.md): Search for STAC items with full-featured filtering. STAC item assets include signed URLs when the number of items returned is below a certain threshold (current default is 5). Implements the STAC API Item Search Specification and STAC API Filter Extension.
- [Simple Search](https://docs.canopy.umbra.space/reference/search_search_get-2.md): Search for STAC items with simple filtering. STAC item assets include signed URLs when the number of items returned is below a certain threshold (current default is 5). For usage information and examples, see https://github.com/radiantearth/stac-api-spec/tree/release/v1.0.0/item-search
- [Get a single STAC Item](https://docs.canopy.umbra.space/reference/get_item_collections__collection_id__items__item_id__get-2.md): Get information about one STAC item by its specific item ID and collection ID. STAC item assets include signed URLs.
- [List all Collections](https://docs.canopy.umbra.space/reference/get_collections_collections_get-1.md): Get a list of all Collections.
- [Get a single Collection](https://docs.canopy.umbra.space/reference/get_collection_collections__collection_id__get-1.md): Get information about a specific Collection.
- [List all STAC Items in a Collection](https://docs.canopy.umbra.space/reference/get_itemcollection_collections__collection_id__items_get-2.md): Get a list of all STAC Items in a Collection.
- [List Delivery Configs](https://docs.canopy.umbra.space/reference/list_delivery_configs.md): Return a list of DeliveryConfigs for the requesting organization id  This endpoint is not paginated because we expect each org to only create a few configs.
- [Post Delivery Config](https://docs.canopy.umbra.space/reference/post_delivery_config.md)
- [Delete Delivery Config](https://docs.canopy.umbra.space/reference/delete_delivery_config.md): Delete a DeliveryConfig by setting it's status to DELETED.
- [Verify Delivery Config](https://docs.canopy.umbra.space/reference/verify_delivery_config.md): Verify a DeliveryConfig by publishing a dummy file to the user's configuration. If the verification succeeds, the DeliveryConfig status will be set to ACTIVE. Otherwise the status will be set to ERROR with more details in status_message.
- [Get Schema](https://docs.canopy.umbra.space/reference/get_schema.md)
- [Preview](https://docs.canopy.umbra.space/reference/preview_cog_preview_get.md): Create preview of a dataset.
- [Get Token](https://docs.canopy.umbra.space/reference/get_token.md): Retrieve the M2M client_id and client_secret for your Organization
- [Rotate Token](https://docs.canopy.umbra.space/reference/rotate_token.md): Rotate the M2M client_id and client_secret for your Organization
- [Create Token](https://docs.canopy.umbra.space/reference/create_token.md): Create the M2M Application for your Organization
- [Delete Token](https://docs.canopy.umbra.space/reference/delete_token.md): Delete the M2M Application for your Organization
- [Get Organization Settings](https://docs.canopy.umbra.space/reference/get_organization_settings.md): Returns Organization Settings for the logged in Organization
- [List All Product Constraints For Logged In Org](https://docs.canopy.umbra.space/reference/list_all_product_constraints_for_logged_in_org.md): Retrieves all product constraints that apply for the logged in organization
- [Get Constraints For Contract Or Org Default](https://docs.canopy.umbra.space/reference/get_constraints_for_contract_or_org_default.md): Returns resolved constraints for either: - a specific contract (when contract_id is provided), - an organization's default contract (when organization_id is provided), or - the requester's organization's default contract (when neither is provided).
- [Get Thumbnail](https://docs.canopy.umbra.space/reference/get_thumbnail.md)
- [Get a single Archive STAC Item](https://docs.canopy.umbra.space/reference/get_item_collections__collection_id__items__item_id__get-1.md): Get information about one Archive STAC item by its specific item ID and collection ID.
- [List all Collections](https://docs.canopy.umbra.space/reference/get_collections_collections_get.md): Get a list of all Collections.
- [Get a single Collection](https://docs.canopy.umbra.space/reference/get_collection_collections__collection_id__get.md): Get information about a specific Collection.
- [List all Archive STAC Items in a Collection](https://docs.canopy.umbra.space/reference/get_itemcollection_collections__collection_id__items_get-1.md): Get a list of all Archive STAC Items in a Collection.
- [Advanced Search](https://docs.canopy.umbra.space/reference/search_search_post-1.md): Search for Archive STAC items with full-featured filtering. Implements the STAC API Item Search Specification and STAC API Filter Extension.
- [Simple Search](https://docs.canopy.umbra.space/reference/search_search_get-1.md): Search for Archive STAC items with simple filtering. For usage information and examples, see https://github.com/radiantearth/stac-api-spec/tree/release/v1.0.0/item-search
